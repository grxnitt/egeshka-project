# Статьи

Каждая статья — один файл `slug.md` в этой папке. Имя файла становится адресом: `content/articles/my-topic.md` → `egematch.ru/articles/my-topic`.

## Как добавить статью

1. Создай файл `content/articles/<slug>.md` (латиница и дефисы) по образцу ниже.
2. Выбери обложку в поле `cover` (`exam`, `market`, `ai`, `scores`) или нарисуй новую в `scripts/make_article_covers.py` и запусти этот скрипт.
3. Собери сайт: `python3 scripts/build_school_pages.py` (или только `python3 scripts/build_articles.py`).
4. Готовый пост для Telegram лежит в `content/telegram/<slug>.txt`: скопируй его в канал.
5. Проверь страницу локально и запушь изменения, Vercel выложит сайт сам.

## Формат файла

```
---
title: Заголовок статьи
description: Одно-два предложения: они идут в лид, поиск и превью в соцсетях.
date: 2026-09-25 12:00
cover: exam
tg: Текст поста для Telegram, 2–3 предложения.
tldr:
- Главное в одном предложении.
- Ещё один вывод.
sources:
- Название источника | https://адрес
---

Первый абзац.

## Подзаголовок

Текст, **жирный**, *курсив*, [ссылка](/ratings).

- Список
- из пунктов

:::stats
154 млрд ₽ | подпись к числу
+12% | подпись к числу
:::

:::callout Что это значит при выборе школы
- Совет читателю.
:::
```

Поддерживается: `##`/`###` заголовки, списки (`-` и `1.`), цитаты (`>`), картинки (`![описание](/путь.jpg "подпись")`), блоки `:::stats` и `:::callout`. Время чтения считается само (около 180 слов в минуту), длина 540–720 слов даёт 3–4 минуты.

## Черновики и снятие статьи

Строка `draft: true` в начале файла (после `date`) убирает статью со списка, из карты сайта и из RSS. Чтобы снять уже опубликованную статью, добавь её и пересобери сайт. Удаление файла тоже работает.

## Правила

- Факты и цифры бери из первоисточников и указывай их в `sources`. Выводы и советы пиши как мнение редакции.
- Не копируй чужие тексты: пересказывай своими словами, цитаты короткие и с указанием источника.
- Реклама и платные размещения помечаются как «Реклама».

## Аналитика: что считается и где смотреть

Сайт отправляет события в Яндекс Метрику (счётчик `113004084`).

**Цели в Метрике** (Настройка → Цели → Добавить цель → «JavaScript-событие», идентификатор точно как ниже):

| Идентификатор | Когда срабатывает | Параметры |
| --- | --- | --- |
| `article_read` | Читатель прокрутил минимум половину статьи и провёл на ней 20 секунд | `slug`, `seconds` |
| `article_finish` | Дочитал до конца текста (97%) и провёл 20+ секунд | `slug`, `seconds` |
| `article_to_telegram` | Клик на Telegram-канал (или бота) из статьи | `slug`, `place` (`card` — карточка внизу, `text` — ссылка в тексте) |
| `article_to_ratings` | Клик на рейтинг школ из статьи | `slug`, `place` |

Общие цели `channel_click` и `bot_open` тоже срабатывают на ссылки в Telegram, в статьях у них `source = article_cta`.

**Отчёты без настройки:** Метрика → Отчёты → Стандартные отчёты → Содержание → **Параметры визитов**. Там дерево «Статьи → <название статьи> → Открыл / Прокрутка 25–100% / Время ≥ 60 и 120 с / Прочитал / Дочитал / Клик: Telegram / Клик: Рейтинг». Так видно, какие статьи читают и дочитывают чаще и в какие статьи чаще кликают дальше. Просмотры статей и источники трафика (в том числе Telegram) видны в обычных отчётах по страницам.

Внизу каждой статьи только две карточки: Telegram-канал и рейтинг школ. Переходы из Telegram-постов (`content/telegram/*.txt`) помечены `utm_source=telegram`.

## Индексация

Уже сделано в коде: карта сайта с датами, RSS с полным текстом, разметка `Article`, `Clean-param` для UTM в `robots.txt`, ссылки между статьями и из шапки, подвала, нижней навигации.

Что делать руками после публикации каждой статьи:

1. Яндекс Вебмастер → Индексирование → **Переобход страниц**: добавить адрес новой статьи (и `/articles`).
2. Опционально: `python3 scripts/indexnow.py`. Скрипт сообщает Яндексу о новых адресах (протокол IndexNow), запускать после деплоя.
3. Опубликовать пост в Telegram (`content/telegram/<название>.txt`) и, по возможности, во ВКонтакте и Дзене со ссылкой: внешние ссылки ускоряют индексацию.
4. Через 3–7 дней проверить Вебмастер → Индексирование → Страницы в поиске.
5. Один раз: Вебмастер → Индексирование → Файлы Sitemap → добавить `https://egematch.ru/articles/feed.xml` (RSS тоже принимается как источник).
