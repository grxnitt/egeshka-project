# ЕГЭшка: главная страница

Адаптивная главная страница, фильтр по предметам, карточки школ и сравнение двух школ или преподавателей одного предмета. Без регистрации и записи отзывов на сайте: кнопка ведёт в действующий бот.

Запуск из корня репозитория:

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory web
```

Открыть http://localhost:5173. Внешний шрифт загружается из Google Fonts; при отсутствии сети используются системные шрифты.

`catalog.json` — снимок публичной редакционной базы бота, не рабочая база пользователей. Обновление: `python3 web/export_catalog.py`. Экспорт не читает SQLite, отзывы, подтверждения, `.env` или токены. `links.json` содержит только публичные адреса бота и канала.

Оценки помечены как предварительные: на сайте нет пользовательских оценок. Запись отзывов, полноценная анкета подбора и синхронизация через API относятся к следующим экранам и этапу подключения сервера. Главная кнопка открывает выбор предмета.
