# Как подключить школу к заявкам

Все команды — в боте @egematch_bot, работают только для ADMIN_IDS. Полный список: `/lead_help`.

1. Договор подписан, школа прислала Приложение 1.
2. Заносим данные (можно частями, повторной командой):
   `/lead_set Умскул | name=ООО «Умскул» | inn=7700000000 | policy=https://umschool.net/privacy | contacts=phone,telegram | tg=-1001234567890 | sales=Иван, @ivan | pd=dpo@umschool.net | rate=300`
   - `tg` — ID чата отдела продаж. Школа добавляет @egematch_bot в свой чат; ID видно, если переслать сообщение из чата боту @getidsbot.
   - `email` — адрес для заявок (amoCRM и Битрикс24 умеют создавать сделки из писем).
   - `webhook` — адрес приёма в CRM. Затем `/lead_secret Школа` и передать ключ школе: каждый запрос приходит с заголовком `X-EgeMatch-Signature: sha256=<HMAC-SHA256 тела>`.
3. `/lead_test Школа` — тестовая заявка с пометкой «ТЕСТ», в отчёт не попадает. Школа подтверждает, что получила.
4. `/lead_on Школа` — включить. Бот не даст включить, пока не заполнены юрлицо, ИНН, канал доставки, контакт по персональным данным и ставка.
5. Пауза: `/lead_off Школа` — кнопка «Выбрать школу» снова ведёт на сайт школы.

Каждый день: `/leads` — сколько заявок, сколько не доставлено и отозвано. Если заявку не удалось доставить за 5 попыток, бот сам напишет админам.

Каждый месяц до 5-го: `/lead_report Школа 2026-11` — файл отчёта (Приложение 3, без контактов учеников) → отправить школе. Принятые споры: `/lead_exclude ID причина`, отмена — `/lead_include ID`. После 5 рабочих дней отчёт = акт; оплата — чек в «Мой налог».
